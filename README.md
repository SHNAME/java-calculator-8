# java-calculator-precourse

# 프로젝트 개요

- 입력한 문자열에서 숫자를 추출하여 **더하는 계산기**를 구현한다.
- 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우 각 구분자를 기준으로 분리한 숫자의 합을 반환한다.
- 기본 구분자 외에 커스텀 구분자를 지정할 수 있다. 커스텀 구분자는 문자열의 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용한다.
- 사용자가 잘못된 값을 입력할 경우 'IllegalArgumentException' 을 발생시킨 후 애플리케이션은 종료되어야 한다.

# 기능 구현 목록

## 계산기 시작 문구 출력 기능

- [] 계산기 시작 문구를 상수화
- [] 계산기를 시작하는 Controller 클래스에서 출력
- [] 'OutputView' 클래스에 구현

## 사용자 입력 기능

- [] 사용자로부터 문자열을 입력받는 함수 구현
    - [] 'Console' 클래스 사용
    - [] 입력한 문자열 반환
    - [] 'InputView' 클래스에 구현

## 연산 구분 기능

- [] 연산을 구분할 수 있는 함수 구현
    - [] 비어있거나 숫자로 시작하는 경우 기본 연산으로 처리
    - [] "//"로 시작하는 경우 커스텀 연산으로 처리
    - [] 그 외 형식은 예외 처리
    - [] 'TypeChecker' 클래스 구현

## 유효성 검증 기능

- [] 기본 연산 검증
    - [] 'BasicOperation' 클래스 구현
    - [] 음수가 입력되었다면 예외 처리
    - [] 마지막 문자가 숫자가 아니라면 예외 처리
    - [] 문자열이 Pattern에 맞지 않는다면 예외 처리

- [] 커스텀 연산 검증
    - [] 'CustomOperation' 클래스 구현
    - [] 문자열 Pattern에 맞지 않는다면 예외 처리

- [] 공통 처리
    - [] 기본/커스텀 연산의 공통 변수 및 기능을 담는 'Operation' 클래스 구현

## 숫자 추출 기능

- [] 기본 연산
    - [] 빈 문자열이라면 0 반환
    - [] 구분자를 기준으로 숫자 분리
    - [] 구분자가 연속 2번 등장하면 예외 처리
    - [] 숫자가 아닌 문자가 있으면 예외 처리
    - [] 추출한 숫자들을 리스트에 저장

- [] 커스텀 연산
    - [] 구분자를 기준으로 숫자 분리
    - [] 숫자 문자가 없다면 0 반환
    - [] 구분자가 연속 2번 등장하면 예외 처리
    - [] 숫자가 아닌 문자가 있으면 예외 처리
    - [] 추출한 숫자들을 리스트에 저장

## 덧셈 기능

- [] 리스트에 저장된 숫자들의 합계를 계산 및 반환

## 계산 결과 문구 출력 기능

- [] 계산기 결과 문구를 상수화
- [] 계산 결과와 함께 문구를 출력
- [] 'OutputView' 클래스에 구현
